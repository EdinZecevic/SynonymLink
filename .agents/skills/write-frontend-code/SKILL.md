# Upute za pisanje frontend koda
- **Tehnologije:** Koristi React (TypeScript + Vite).
- **Stiliziranje:** Koristi čist CSS (Vanilla CSS). Izbjegavaj TailwindCSS osim ako se izričito ne zatraži. Fokusiraj se na moderan, premium dizajn (glassmorphism, glatke animacije, harmonijske boje, responzivnost).
- **API komunikacija:** API pozive obavljaj kroz namjenski API klijent u frontend kodu koji koristi `VITE_API_URL` okolinsku varijablu.
- **Lokalizacija:** Pripazi na i18n podršku (svi korisnički tekstovi trebaju ići kroz konfigurirane datoteke s prijevodima).
